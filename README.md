# vrcnext-plugins.github.io

Documentation site for [VRCNext Plugins](https://vrcnext-plugins.github.io/), built with GitHub
Pages and Jekyll.

Every page is plain Markdown at the repository root. Jekyll rewrites `.md` links to `.html`, so
internal links are written as `getting-started.md` and resolve correctly once published.

The project itself lives in
[vrcnext-plugin-system](https://github.com/vrcnext-plugins/vrcnext-plugin-system).

## Local preview

```bash
bundle exec jekyll serve
```
